    Mission 3: Bring Your Own Channel (BYOC)

    Story

    If the customer wants to use a custom channel, which is not supported by Webex Contact Center natively, they can integrate it with Webex CC using Bring Your Own Channel (BYOC) capability. Such integration significantly expands the number of options available for end customers to contact companies, partners or service providers via Webex Contact Center through a variety of different digital channels, including social media and custom channels. This makes the entire communication much easier and convenient for the end customers regardless of what type of communication they prefer.

    Call Flow Overview

    1. Contact center administrator establishes integration with the external custom channel and subscribes it to receive messages and events from Webex CC.
    2. A new request is initiated by the end customer and triggers custom messaging flow.
    3. The flow interacts with the customer to gather the details necessary to process the request.
    4. The flow extracts the data from customer responses, prepares necessary info for the agent, and routes the request to the queue for further assistance.

    Mission Details

    Your mission is to:

    1. Get webhook URL of the external message recipient and subscribe it to the messages and events from Webex CC.
    2. Build a custom messaging flow in the unified flow designer.
    3. Set up chat request routing depending on the topic.
    4. Test message exchange between the customer and the agent.

    Build

    1. Open your web browser or a new tab in an existing web browser window and navigate to UseWebhook site. Then click on the Copy URL button next to the webhook URL at the top of the page to make a copy of the URL. Please keep this browser tab open to avoid changing your unique webhook URL.

    2. Log in to Webex Contact Center Developer Portal by using your Admin profile. Your login will be of the format wxcclabs+admin_IDYour_Attendee_ID@gmail.com. If you did not sign in to the Collaboration Control Hub or the other resource under the same admin account in the same web browser session yet, you will see another login screen with the Webex logo on it where you may need to enter the email address again and the password provided to you.

    3. Let's subscribe your webhook URL to receive Webex Contact Center events via the Subscriptions API. Go to the Register Subscription section of Webex Contact Center Developer Portal. Switch to Request Body (JSON) tab in the window on the right-hand side, then copy the JSON body below, paste it there, scroll down and press the Run button:

    5. Open a new tab in your web browser and log in to Collaboration Control Hub by using your Admin profile. Your login will be of the format wxcclabs+admin_IDYour_Attendee_ID@gmail.com.

      Note

      Remember to take up the offer from Chrome to save your password.

    6. Click on the Contact Center item under the SERVICES section on the left pane. Then go to Assets under DIGITAL SETTINGS section on the left. Click on Custom messaging tab at the top, search for your asset Your_Attendee_ID_BYOC_Asset and click on it to go to the asset settings.

    7. Set the following parameters in the Webhook section of asset settings and save changes:

      • Messaging webhook URL: [webhook URL from step 1]

      • Messaging webhook secret: secret-string-to-sign-event-payloads

    8. Navigate to Flows under Customer Experience section on the left, click on Manage Flows dropdown list on the top right and select Create Flows.

    9. New Flow creation tab will be opened. Select Flow and Start from scratch in that tab and press Next.

    10. On the Flow configuration tab name your flow as BYOC_Flow_Your_Attendee_ID Then select Common_BYOC_Channel as a channel type and click on Create Flow. The new flow, with only the Start Flow node on the flow canvas will be created.

      Note

      • Edit toggle at the top center of the page should be turned on when you create a new flow. If the toggle is off, switch it to on.
      • Autosave toggle at the bottom right of the page should also be turned on. If it is off, turn it on.

    11. Click on any empty point on the flow canvas to see Global flow properties tab on the right-hand side. Then go to that pane, scroll down to the Configuration - Flow Variables and create the following variables by pressing the Create flow variable button:

      • Name - order, Variable type - String, Agent viewable - On, Desktop label - Order number

    12. Scroll down and turn on Enable decryption toggle on the same Global flow properties tab.

    13. Add Send Custom Message node from the Activities pane on the left to the main flow canvas and set the following node settings:

      • Activity label: SendHello

      Channel details section:

      • Custom messaging channel: Common_BYOC_Channel

      Message configuration section:

      • Message type: Text

      • Message text: Hello, Please provide your order number.

      • Append message to transcript: Enabled

      Connect Start Flow node output to this node.

    14. Add Receive Message node from the same Activities pane and set the following node settings:

      • Activity label: ReceiveOrder

      Channel details section:

      • Channel type: Custom Messaging

      • Channel: Common_BYOC_Channel

      • Wait before timing out: 600 seconds

      • Append message to transcript: Enabled

      Parse settings section (press + Add new button to add a variable):

      • Flow variable: order

      • JSON path expression: $.message.text

      Connect SendHello node output to this node.

    15. Add one more Send Custom Message node to the flow and set the following node settings:

      • Activity label: SendSuccessResponse

      Channel details section:

      • Custom messaging channel: Common_BYOC_Channel

      Message configuration section:

      • Message type: Text

      • Message text: Thank you for providing the information. We appreciate your patience. One of our agents will join the chat shortly to assist you.

      • Append message to transcript: Enabled

      Connect ReceiveOrder node output to this node.

    16. Add one more Send Custom Message node to the flow and set the following node settings:

      • Activity label: SendErrorResponse

      Channel details section:

      • Custom messaging channel: Common_BYOC_Channel

      Message configuration section:

      • Message type: Text

      • Message text: It looks like an issue may have occurred during the chat. One of our agents will join shortly to investigate and assist you. Thank you for your patience.

      • Append message to transcript: Enabled

      Connect all Timeout and Undefined Error outputs of SendHello and ReceiveOrder nodes to this node.

    17. Add Queue Contact node to the flow and configure it in the following way:

      • Channel type: Custom messaging

      • Static queue

      • Queue: Your_Attendee_ID_BYOC_Queue from the drop-down list

      Connect all outputs of SendSuccessResponse and SendErrorResponse nodes to this node.

      Note

      As mentioned in Getting Started, all queues have been preconfigured so you don't need to change any of them at this step.

    18. Add End Flow node and connect the output of Queue Contact node to this node.

    19. Validate and publish the flow:

      • Enable the Validation toggle in the bottom right corner of the flow designer window to check for any potential flow errors and recommendations.

      • If there are no Flow Errors after validation is complete, click on Publish Flow next to it.

      • In the pop-up window, ensure that the Latest label is selected in the Add Version Label(s) list, then click Publish Flow.

    20. Return to the Contact Center on Collaboration Control Hub. Go to Entry Points, search for your channel Your_Attendee_ID_BYOC_Channel and click on it.

    21. In Entry Point settings section change the following, then click Save button:

      • Chat routing flow: BYOC_Flow_Your_Attendee_ID

      • Version label: Latest

    Testing

    1. Make sure you're logged in to the Webex CC agent desktop as an agent and set the status as Available for all channels.

    2. Navigate to Create Task API of Webex Contact Center Developer Portal and make sure you signed in with your Admin profile. Then switch to Request Body (JSON) tab in the window on the right-hand side.

      Note

      As mentioned at the beginning of this mission, we will use Create Task API for two purposes:

      • Initiate a new request via custom channel on behalf of customer and trigger Webex CC flow starting a conversation.
      • Append message to the existing conversation on behalf of customer.

      In other words, we will use Create Task API to simulate custom channel interface on customer's side. For example, if the end customer sent those messages via Instagram, Telegram, LinkedIn or any other application.

    3. Firstly, let's initiate a new request on behalf of the end customer to trigger Webex CC flow we created above. Copy the JSON body below, paste it to Request Body (JSON) tab, scroll down and press the Run button. This will send a message Hello, I need help with my order. to Webex CC and call your flow.

      Note

      Please replace the following parameters in JSON body below before executing API request:

      • [The email from your Webex CC lab Admin account] - wxcclabs+admin_IDYour_Attendee_ID@gmail.com
      • [The name of your BYOC Entry Point] - Your_Attendee_ID_BYOC_Channel
      • [Current time in EPOCH format with milliseconds] - use Epoch Converter to get the timestamp in the proper format. For example, 1795636326000
      {
    "origin": {
        "address": "email@example.com",
        "name": "Customer Inc.",
        "type": "customerAddress"
    },
    "destination": {
        "address": "[The email from your Webex CC lab Admin account]",
        "name": "Webex CC Inc.",
        "type": "businessAddress"
    },
    "channelProperties": {
        "channelType": "customMessaging",
        "channel": "[The name of your BYOC Entry Point]",
        "message": {
            "direction": "inbound",
            "type": "text",
            "text": "Hello, I need help with my order.",
            "timestampEpoch": "[Current time in EPOCH format in milliseconds]"
        }
    }
}

    4. After your flow receives initial message, it will auto-reply with the message Hello, Please provide your order number. that we preconfigured when creating the flow. Both messages will be sent to webhook URL provided during subscription registration above. Therefore, switch to the Webhook website tab in your browser and make sure you see both messages there.

    5. Now, let's append an existing conversation with the new message on behalf of the end customer to route it to the queue and engage an agent. We will reply with the text 123456 as an order number.

      Note

      To simplify lab task and flow logic, we do not make any verification within the flow whether provided value really matches order number format. However, this is a mandatory part of any BYOC implementation in a production environment.

      To do this, navigate to Append Task Message API of Webex Contact Center Developer Portal and switch to Request Body (JSON) tab in the window on the right-hand side. Then copy the JSON body below, paste it to Request Body (JSON) tab, scroll down and press the Run button:

      Note

      Please replace the following parameters in JSON body below before executing API request:

      • [The name of your BYOC Entry Point] - Your_Attendee_ID_BYOC_Channel
      • [Current time in EPOCH format with milliseconds] - use Epoch Converter to get the timestamp in the proper format. For example, 1795636326000
      {
    "channelProperties": {
        "channelType": "customMessaging",
        "channel": "[The name of your BYOC Entry Point]",
        "message": {
            "direction": "inbound",
            "type": "text",
            "text": "123456",
            "timestampEpoch": "[Current time in EPOCH format in milliseconds]"
        }
    }
}

    6. Switch to the Webhook website tab in your browser and make sure you see the appended messages with order number there.

    7. Switch to the agent desktop browser tab and accept incoming request.

    8. Send messages from the customer to the agent (via Append Task Message API) and vice versa (from the agent desktop) to make sure bidirectional message exchange works correctly. Make sure you see all those messages on the Webhook webpage. Then end the conversation in agent desktop, select any value from the Wrap Up Reasons dropdown list on the right-hand side, and press the Submit Wrap Up button.

    Congratulations, you have successfully completed Bring Your Own Channel mission! 🎉🎉
